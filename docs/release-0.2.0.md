# 咏伴 0.2.0

网易云连接与安装路径设置更新，并更换程序图标。

- 网易云已运行时，点击「连接客户端」会询问是否重启。确认后自动关闭、重启并等待客户端双向同步；取消或 Esc 保留当前播放。
- 首次启动提示确认网易云音乐路径，自动识别目录并预填，支持浏览或粘贴主程序路径。
- 「设置 → 网易云音乐路径」可随时修改目录，保存后下次连接生效。
- 保存前校验路径，配置原子写入；连接防止重复点击，并提示路径、权限、安装实例冲突和连接超时。
- 新的绿色音符与歌词图标，包含 16–256 像素资源，嵌入 EXE 并用于窗口与任务栏。
- 保留原有歌词注音、译文、查词、客户端播放控制、本地变速和循环功能。

下载 `Utatomo-0.2.0-windows-x64.zip`，完整解压后运行 `Utatomo.exe`。适用于 Windows 10 / 11 x64，无需安装 Python；请保留 `_internal` 文件夹。更新时保留原 `data/`，旧显示偏好和注音修正仍可使用；首次升级会提示确认安装路径。

重启会中断播放；客户端无法正常退出时，工具会结束同一安装路径下的网易云进程。已经直连时不会再次重启。其他版本的网易云可能需要适配，当前直连验收版本为 3.1.41.205529。

验证：62 项离线单元测试、46 项真实 WebEngine 界面检查、8 项真实本地播放器检查，以及 7 项真实客户端路径保存、取消与重启连接检查全部通过。测试使用临时配置，实际重启后恢复了同曲播放状态。

便携版已构建并通过相同的 8 项播放器验收，首次启动弹窗与标题栏图标经过原生窗口检查；EXE 的七个图标图层与源图一致。压缩包包含完整依赖和许可证，不含个人数据。

程序未做代码签名，下载包附 `SHA256SUMS.txt` 与第三方许可证。使用方法见 [README](https://github.com/AsaMisogi/Cloudmusic-Lyrics-Singing#readme)，项目采用 GPLv3。
