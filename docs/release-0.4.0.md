# 0.4.0 · 粤拼与个人练唱曲库

## 新增

- **中文粤拼**：默认关闭；开启后在中文原文上方显示带 1–6 声调数字的离线粤语读音，支持简繁体与本句修正。日语、英语和中文译文保持各自处理方式。
- **最近播放**：本地与网易云分别保留最近 500 首，支持即时搜索、来源筛选、分页及一键播放。只记录实际播放，重复歌曲合并。
- **曲库收藏**：当前歌曲一键收藏，多选本地文件，搜索或粘贴网易云歌曲链接。支持本地新建、重命名、删除歌单，歌单可混合两种来源，也可从最近播放加入歌曲。
- **文件重新定位**：移动过的本地歌曲可关联新路径，合并既有收藏、历史和歌单；不复制或删除音频。

## 修复与体验

- 移除设置和注音弹窗的背景模糊，弹窗期间停止背景高频重绘，音频及同步继续运行。
- 注音保存改为局部更新，保留行对象、浏览位置和循环；失败保留输入并给出原因。
- 统一侧栏入口、来源标签、焦点、按下反馈及辅助文字对比度；大列表按 50 首分页。
- 网易云列表切歌经现有直连通道后台派发播放，不启动或激活客户端。普通 SMTC 模式请先点「连接客户端」启用直连；正在运行时会先询问是否重启。原同步、播放与暂停能力保留。
- 曲库使用 SQLite 事务保存；音频身份与歌词版本分离，兼容缺少 ID 的系统媒体记录，补全后自动合并。

## 0.4.0 同版本修订 · 试用反馈

- 修复启动协议切歌会唤起网易云窗口的问题，改用后台直连播放，不做焦点争抢或事后隐藏。
- 修复日文字体缺少部分简体字形导致的粗细混用；歌词常规字重统一，新增「设置 → 歌词文本字体」本机字体选择、预览及持久保存。
- 已最爱显示深色实心红心；曲库左侧新增固定「最爱」。取消红心保留曲库和歌单，导入与加入歌单不自动点亮红心。
- 封面下增加「加入歌单」；全局曲库移除与最爱、歌单移除使用不同入口和明确说明。
- 原有曲库自动迁移，既有红心与歌单保留。应用版本保持 0.4.0。

## 升级与测试

退出旧程序，把新包完整解压到新目录，再复制原 `data/`。不要混用旧 `_internal/`。粤拼旧设置默认关闭，既有日语/英语注音修正保留；新曲库保存在 `data/library.sqlite3`。本地歌单不会同步到网易云账号。

便携包名：`Utatomo-0.4.0-windows-x64.zip`，附 `SHA256SUMS.txt`。新增离线依赖 ToJyutping 3.2.0，BSD 2-Clause 许可原文与词典一同打包。

重点试用：开启/关闭粤拼；播放时反复打开设置和修正；最近播放切歌；混合来源歌单；移动本地文件后重新定位。闪烁修复仍需在原反馈用户的显卡与缩放环境复测。

本地构建和验收记录见 [verification.md](verification.md)。用户试用确认后，以 v0.4.0 正式 Release 发布；上传包体包含上述同版本修订。支持更新检查的旧版工具可识别 0.4.0 并前往发布页下载。
