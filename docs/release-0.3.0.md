# 咏伴 0.3.0

新增日语罗马音显示开关、GitHub 项目入口与正式版本更新提醒。

- 顶部新增「日语罗马音」开关，默认关闭并自动记住偏好。开启后日语注音按整词显示罗马音，纯假名词同样提供注音；英语 IPA 保持原样，注音总开关可同时隐藏罗马音。
- 罗马音基于当前歌曲读音与用户修正离线生成，助词按词典上下文发音转换。切换保留播放位置、逐字高亮、循环与手动浏览状态；词典显示随模式切换，修正注音仍编辑假名。
- 侧栏「GitHub 项目」可打开源码和反馈页；设置顶部新增当前版本、「检查更新」和发布页入口。
- 每次启动在后台检查一次 GitHub 最新正式 Release，发现新版本后自动提示；点击「前往 GitHub 下载」在系统浏览器打开对应版本页。
- 更新弹窗显示当前和最新版本，支持稍后、关闭及 Esc；首次路径引导或其他弹窗打开时等待其关闭，避免打断当前操作。
- 手动检查提供无更新、网络失败、接口异常和限流反馈，检查中禁止重复点击。启动检查无更新或失败时保持安静；更新任务不阻塞界面，不受切歌影响。
- 保留客户端路径与连接、歌词跟随、日英注音、中文译文、查词、快捷键、本地播放、变速与循环。

下载 `Utatomo-0.3.0-windows-x64.zip`，完整解压后运行 `Utatomo.exe`。适用于 Windows 10 / 11 x64，无需安装 Python，请保留 `_internal` 文件夹。升级前退出旧版，把新包解压到新目录，再复制原 `data/` 文件夹以沿用个人数据；不要混用旧依赖。

检查仅访问 GitHub 公开发布信息，无需登录，不自动下载安装。匿名 API 可能受网络或限流影响，可稍后重试或直接查看发布页。

验证：78 项离线单元测试、76 项真实 WebEngine 界面检查、13 项真实键盘检查、11 项真实 WebChannel / 后台线程更新与罗马音流程检查通过。原有本地播放器 12 项验收通过，前端无脚本错误；更新链路使用固定 Release 响应与假浏览器，不改个人设置、不重启网易云。真实 GitHub 匿名接口的限流反馈已验证，通过已登录接口核对实际 Release 格式。

下载包附 SHA256 校验文件和第三方许可证。更多说明见 [README](https://github.com/AsaMisogi/Cloudmusic-Lyrics-Singing#readme)，项目采用 GPLv3。

Windows x64 便携版构建完成，直接运行打包 EXE 的 12 项播放器验收通过；压缩包完整性、SHA256 和最终界面资源已核对，不包含个人数据、缓存和测试输出。
