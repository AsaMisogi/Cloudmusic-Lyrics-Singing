# 咏伴 0.7.0 · 练唱工作区

- 「练唱谱」旁直接切换注音、译文、罗马音、粤拼和查词典。即使旧版本收起了显示栏，升级后也会看到这些开关，原有开关值不变。
- 播放来源和连接操作集中在左上角。连接方式、歌词出处和时间轴说明改从左栏「播放信息」查看。
- 封面、歌名、歌手、收藏和加入歌单移入底部播放器；谱面不再为曲目信息和诊断状态留空。
- 查词时标记选中的词，修正注音和在线查询有独立按钮。窗口标题栏跟随当前主题（Windows 11 支持自定义颜色），保留系统窗口行为。
- 便携版沿用现有资料结构。测试新版时可先解压到另一目录；要带入练唱资料，在旧版「设置 → 启动与备份」导出，再在新版恢复。
