# 咏伴 0.9.0 · 间奏留句与软件内增量更新

- 桌面歌词遇到空行，保留本曲上一句符合当前显示选项的内容。只看译文或注音时也适用；倒拖、切歌不会沿用错误的句子。
- 在「设置 → 连接与更新」检查新版、下载增量补丁，再点「重启并更新」。默认国内加速优先，也可固定国内源或 GitHub 直连。下载前显示补丁或完整包大小；签名校验通过才安装。
- 更新提示与设置都保留 GitHub 发布页和[百度网盘](https://pan.baidu.com/s/1ZKFEDhp-ZP8Tc7GGMzRvMg?pwd=kzx8)（提取码：`kzx8`）。

**正在使用 0.8.3？** 旧版的更新按钮仍会打开此页。从下方下载 [0.8.3 → 0.9.0 小补丁](https://github.com/AsaMisogi/Cloudmusic-Lyrics-Singing/releases/download/v0.9.0/Utatomo-0.8.3-to-0.9.0-patch.zip)，解压到单独的空文件夹，从托盘退出旧版，再双击补丁顶层的 `Utatomo-Update.exe`，选择旧目录里的 `Utatomo.exe`。不需要重新下载完整包，不要把补丁直接覆盖到旧目录。

**首次安装或更早版本：** 下载 [Windows x64 便携包](https://github.com/AsaMisogi/Cloudmusic-Lyrics-Singing/releases/download/v0.9.0/Utatomo-0.9.0-windows-x64.zip) 并完整解压。迁移时退出旧版，复制旧目录的 `data/`。从 0.9.0 起，下次更新可直接在软件内完成。

国内加速：[补丁](https://gh-proxy.org/https://github.com/AsaMisogi/Cloudmusic-Lyrics-Singing/releases/download/v0.9.0/Utatomo-0.8.3-to-0.9.0-patch.zip) · [便携包](https://gh-proxy.org/https://github.com/AsaMisogi/Cloudmusic-Lyrics-Singing/releases/download/v0.9.0/Utatomo-0.9.0-windows-x64.zip)。`update.json` 供软件读取，用户不用手动下载。
