# 架构与维护

## 技术选择

Python 3.12 + PySide6 / Qt 提供原生窗口、文件选择框和本地音频播放。Qt WebEngine 承载 HTML/CSS/JavaScript；QWebChannel 连接界面和控制器。客户端同步使用 websocket-client 连接网易云自身的回环调试端口；工具没有后台 HTTP 服务。

选择这套组合，是因为 Windows 媒体会话、日语形态分析和音频播放都已有成熟实现。前端无 JavaScript 运行时依赖；普通用户只需双击 BAT。Qt WebEngine 安装体积较大，但界面排版、ruby 注音和原生播放器能够一起工作。

网易云 3.1.41 的系统媒体会话不提供时间轴，所以主路径分为：

1. **客户端直连**：读取实际播放器组件的歌曲 ID、时间和状态；通过客户端已有 `playing/setPlayingPosition` 动作跳转，播放按钮控制客户端音频。VIP / 网盘等曲目均由客户端处理播放权限。
2. **兼容接口**：未连接客户端通道时使用 Windows GSMTC，按真实能力开放控制。
3. **本地练唱**：导入普通音频文件，由 QMediaPlayer 提供独立播放、变速和精细循环。

不安装网易云插件、不改安装目录、不扫描进程内存。公开资源缺失时保留明确的本地导入路径。

## 线程与切歌一致性

- Qt 主线程拥有 QMediaPlayer、窗口和全部可变界面状态。
- 一个 asyncio 线程持有 WinRT 媒体会话，以 250 毫秒间隔读取网易云状态；控制请求通过同一事件循环串行发送。
- 客户端连接另用一个单线程 executor，以约 100 毫秒间隔读取状态，阻塞网络操作不进入 GUI 线程。WebSocket 读写共用此队列，响应根据请求 ID 配对。断线后每 3 秒重新发现主页面。
- 客户端指令携带发出时的歌曲 ID；切歌后到达的旧指令会被拒绝，避免误操作新歌。
- 一个词法分析线程串行使用 Fugashi，避免跨线程共享其原生词典实例。
- 三个网络工作线程提供搜索、词典与资源获取。网络设置连接 / 读取超时。
- 换歌和替换歌词增加 `generation`。每个歌曲相关后台结果携带该编号，过期结果被丢弃；尚未开始的旧任务直接取消。
- 工作线程通过 Qt 信号回主线程处理结果，不直接操作 UI。
- 重复词汇或翻译采用文件缓存；临时文件写完后原子替换，避免下载中断损坏正式缓存。

## 时间模型

全部歌词时间与播放器定位使用整数毫秒。前端每帧只在最近播放器时间快照基础上做显示平滑，数据更新仍来自真实播放器；快照过久不会无限推算。

播放中的相同进度快照不重置动画时钟；小误差用最多 25% 的速度校正连续收敛，避免句边界倒退。明显跳转、循环回跳、歌曲身份改变直接重定位；暂停停止外推。进度持续不变时，最多外推 1.5 秒。原文与 ruby 在当前行和其他行使用相同字重，避免高亮改变换行；歌词容器禁用浏览器滚动锚定。逐字进度按各自字符范围计算，保留停顿和重叠。

## 歌曲注音

LRC / YRC 分别保留 romalrc / yromalrc，不混用不同时间轴的读音。读音行在 350 毫秒内一对一匹配，随后以原文假名、送り仮名和词典词边界进行对齐；最佳边界存在歧义或差异过大时回退词典。空格分隔的罗马音保留 n 音节边界，兼容常见罗马音拼法与长音。英日混行暂保留词典注音。

歌曲注音使用词典缓存的副本，避免跨曲污染。新校正单独保存到 song-overrides.json，键由歌曲 ID（本地模式为音频路径）、句时间与原文、词位置组成；切换到不同时间或文本的歌词版本后需重新校正。工作线程捕获加载时的歌曲范围，过期词汇操作会被拒绝。overrides.json 的旧版全局校正仍兼容读取，本句修正优先。

读音优先级现为用户修正（本句高于旧全局）、assets/reading-corrections.json 的歌曲勘误、原文括号注音、歌曲罗马音、词典。勘误按歌曲 ID、句前缀与词位置匹配，附核对来源。词典与罗马音的分歧通过 readingCandidates / readingConflict 传给界面；不把多个机器结果一致当作听音确认。rubyParts 以词内所有假名为锚点，唯一对齐时分开汉字组；有歧义则保留整体读音。

Services.lyric_options 在首选时间轴存在极短歌词行时，从已有搜索候选中读取最多两个同标题、同歌手且时长相差不超过 2.5 秒的条目。用去除注音后的歌词内容相似度（至少 0.85）核对；排序优先完整、异常少、真实逐字时间。候选版本记录 sourceSongId，播放身份和注音校正范围仍使用原歌曲 ID。异常和替代来源在界面显式显示，原版本始终保留；不合成或拉伸未知的演唱时间。

本地 QMediaPlayer 位置快照约每 80 毫秒发送一次，循环边界每 20 毫秒检查。GSMTC 依赖播放器的 `last_updated_time`，只在有效时间轴上外推；1601 年初始时间戳不会被当成当前时间。

LRC 行内进度按行起止时间估算。YRC / 增强 LRC 保存来源中的字词时间。无时间纯文本只显示和查词。

网易云 3.1.41 的滑块以歌曲时长的千分之一量化，回传并非采样级时钟。前端拖动后保留最多 1.8 秒预览，匹配回传位置后交还真实时钟；失败时清除预览。不能把界面的毫秒数当成客户端承诺的毫秒精度。

歌词列表只在换行时切换行状态，每帧仅更新当前行字词。滚动按毫秒计算衰减，并为末段保留至少一个设备像素，避免高 DPI 下滚动卡在中心附近。居中模式首尾各预留半屏；ResizeObserver 在字号、布局变化后重新计算目标。手动滚轮、触摸浏览、滚动条拖动和翻页键默认持续暂停跟随；点击返回或显式跳转恢复。设置可开启 4 秒自动恢复。

Chromium 初始化前追加 `--disable-frame-rate-limit`；不关闭 GPU 加速。暂停且没有动画时以 80 毫秒间隔请求下一帧。屏幕切换通过 Qt screenChanged 更新刷新率信息。

## 文本与资源边界

原文、译文和词典结果都经 `textContent` 写入 DOM；从外部获取的文字不会执行脚本。QWebEnginePage 只允许项目入口作为主页面，用户点击的 HTTPS 外链交给系统浏览器。QWebChannel 不暴露通用脚本执行、命令执行或任意路径读写。

同步音频直接由网易云播放，不再从公开音频地址另取一份。歌词缓存和运行日志仅保存在项目目录。首次安装使用项目内 Python 和虚拟环境。

CDP 仅接受 `127.0.0.1:9222` 或同端口 localhost 的 WebSocket 地址，只选择 `orpheus://orpheus/pub/app.html`。不跟随 HTTP 重定向，不经过系统代理。适配器只返回当前歌曲元数据、播放状态和客户端提供的本地音频路径，不读取账户凭据。调试端口本身赋予同机进程控制客户端的能力；README 说明启动与关闭方式。只有用户确认当前重启弹窗后，工具才允许结束安装路径匹配的网易云进程。

## 客户端路径与连接流程（0.2.0）

- `ClientSettings` 在 `data/settings.json` 保存 `cloudMusicDirectory`。没有成功保存记录时显示首次引导，自动发现仅预填，不代表用户已确认。旧目录失效时保留原值并提示修正，不静默切换安装。
- 自动发现顺序为运行中的 `cloudmusic.exe`、HKCU/HKLM 两种注册表视图的 App Paths / CloudMusic 卸载记录、常见安装目录。目录和主程序路径均可输入，统一检查存在的 `cloudmusic.exe` 并保存绝对安装目录。写入使用同目录临时文件和原子替换。
- 连接准备和重启使用独立的单线程 `launch_pool`，不被歌曲请求取消，也不阻塞 Qt 主线程。控制器持有 busy 状态和一次性确认目录，忽略重复点击；取消或 Esc 不执行任何退出操作。
- 检查完成后、真正启动前再次枚举进程；期间新出现的客户端仍需确认。重启按进程名和完整可执行路径双重匹配；发现其他安装或无读取权限时停止并报告。
- 先通过 Windows `WM_CLOSE` 请求退出，等待 4 秒；剩余同路径进程使用 psutil 校验进程身份后结束，再等待最多 5 秒。全部退出后才用参数列表启动同一主程序，仅开放回环 9222 端口。安装文件不被修改。
- 只有真实 `transport=client` 播放快照到达才宣告连接成功；30 秒没有快照则报告检查建议、释放按钮，原媒体线程继续自动重连。已直连时不再重启。
- 关闭工具时等待已确认的客户端启动任务完成，避免在客户端刚退出时中断后续启动；尚未开始的任务取消。
- 图标以 SVG 为源，Qt 渲染器生成七个尺寸的 PNG 并组成 ICO。PyInstaller 将 ICO 嵌入 EXE，Qt 窗口也使用 ICO；Windows 任务栏身份为 `ASOGI.Utatomo`。

歌词候选按当前 ID、队列、标题 / 歌手相似度、专辑和时长排序。自动获取失败最多尝试三个候选；手动选择不触发自动改选。YRC / LRC 分别配对 ytlrc / tlyric，明显残缺的 YRC 降级到完整 LRC。

## 退出行为

BAT 同步调用 Python，后端和 Qt 主窗口属于同一个进程。Qt 退出时停止音频、关闭媒体线程、取消未开始的工作，再退出 Python。仍在等待网络响应的工作线程不会拖住关闭动作。BAT 成功后直接结束；启动失败时保留日志并等待按键。

关闭日志控制台时，Windows 结束附属进程；Qt WebEngine 子进程随主进程失去连接而退出。用户正在运行的网易云进程不属于这个进程树。

## 修改建议

- 改歌词格式时扩展 `tests/test_lyrics.py`，尤其测试毫秒边界、空白间奏和漏译行。
- 改注音时保留原始字符串重组验证，防止空格、英文所有格被分词器丢失。
- 改播放行为时运行 `--smoke-test`，查看 JSON 结果和真实窗口截图。
- 改外部服务时运行 `scripts/verify_online.py`；普通单元测试不依赖外网。
- 更新依赖时重新生成 `uv.lock`；用户启动脚本以 `--frozen` 使用锁定版本。

## 已知边界

日语歌词可能使用人名、古语、双关或特殊指定读法，普通形态分析无法保证百分之百准确；用户注音修正是正式功能。英语音标是词典美式宽式发音，不是连读和歌唱音节检测。

网易云 / 有道公开接口和免费翻译服务没有本项目可控制的可用性保证。服务失败保留本地导入路径。客户端适配依赖网易云 3.x 的 React 播放组件和动作名，版本升级可能需要更新 client_bridge.js；找不到匹配组件时不宣称可跳转，降级到 GSMTC。


## 紧凑界面与交互偏好（2026-10-02）

- 顶部去除宣传标题，工具按显示、版本与跟随、状态信息分组。折叠按钮使用 aria-expanded / aria-controls，搜索与设置保持可访问。
- `utatomo-display` 沿用持久 WebEngine profile，新增 `collapsed`、`playOnLyricSeek`、`resumeAfterBrowse`。缺少字段时分别使用全展开、开启、关闭；兼容旧显示偏好。初始化先读齐所有字段，再触发保存。
- 歌词高亮框随内容宽度收缩；删除固定最小行高，保留 ruby 自然高度。侧栏在小窗口缩小封面和留白，保留必要时的可滚动能力。
- `seekAndPlay` 为单次有序操作：客户端 await 定位动作后重新校验歌曲 ID 与播放状态；GSMTC 在锁内定位成功后请求播放；本地播放器先定位再播放。进度拖动、微调和循环仍发送 `seek`。
- 封面通过网络池获取 300px 位图，按真实歌曲 ID 缓存，data URL 经 QWebChannel 传递，无须放开 WebEngine 网络权限。回调独立按播放 identity 校验，歌词版本更新不会丢弃封面，切歌后旧图片不会覆盖新图。联网失败使用默认插画。

## 主界面快捷键分派（0.2.1）

`web/app.js` 在 document 捕获阶段处理已绑定快捷键，取消默认行为与后续传播，避免控件焦点引起播放键变成开关、选项或滑块操作。空格 keyup 同样取消原生激活。未绑定键保留控件交互；文本输入、contenteditable、输入法组合和模态弹窗不拦截。方向键允许连续操作，播放和循环切换忽略自动重复事件。

## 应用更新（0.3.0）

- 使用 [GitHub Latest Release API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)，匿名 HTTPS 读取仓库维护者指定的最新正式版。响应必须为 200、JSON 对象，且 draft / prerelease 均为 false。正式标签使用可选 v 前缀及三段数字，与当前版本按整数元组比较；不把日期、标签排序或字符串大小当成版本新旧。
- 请求使用现有 requests 依赖，连接 / 读取超时分别为 3.05 / 7 秒，保留默认 TLS 校验，不跟随重定向，不自动重试。403 / 429、404、其他 HTTP 错误、离线和无效响应均返回失败，不冒充最新版本；下次启动或手动操作可以重试。公共 API 限流时可通过发布页访问下载。
- 独立单线程 update_pool 复用已有后台任务与 Qt 信号回主线程机制；不进入歌曲 pending 队列、不携带歌曲 generation，因此切歌不会取消更新。update_busy 合并重复检查，手动加入正在进行的启动检查时提升为完整反馈。退出时取消排队任务，晚到结果不更新界面。
- WebChannel initialize 完成后每个进程自动检查一次；无更新或失败只结束忙状态并记录错误日志，发现新版才发送提示。手动检查始终反馈结果。--smoke-test 跳过自动联网，以保持播放器回归稳定；专用 verify_updates.py 用临时数据、固定 HTTP 响应、真实桥接和工作线程单独覆盖更新链路。
- 前端从后端读取当前版本，侧栏和设置共用 __version__；发布时同步 pyproject.toml、uv.lock 与 __init__.py。更新提示等待路径引导或其他模态窗口关闭，避免抢占焦点；手动检查发现新版时关闭设置再提示，Esc / 关闭 / 稍后均不触发浏览器。
- GitHub 入口和发布页固定为本仓库地址，特定版本页仅由已经验证的标签构造；不使用响应 html_url 或前端输入的 URL。下载按钮调用 QDesktopServices.openUrl，启动失败给出提示；没有自动下载、执行、覆盖文件或上传个人数据。升级按 README 完整解压并迁移 data/，保留新包依赖。
