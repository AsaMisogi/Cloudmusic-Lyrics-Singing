# 从 0.4.0 升级：0.5.0–0.8.3 新功能

- **0.5.0 · 把歌词放到桌面。** 新增可穿透鼠标的歌词浮窗、托盘控制和开机自启。歌词可从文件导入或直接粘贴，支持括号注音、多个歌词版本和逐句分段；设置、曲库和练唱稿可一起备份、恢复。
- **0.6.0 · 为一句歌词标出换气点。** 行旁可编辑原文、假名和音译，也可恢复原句。谱面和浮窗支持三种水平对齐；浮窗可逐字着色、滚轮调字号、拖边改宽。主窗口新增紫灰、海雾、琥珀三套主题及可自定义的亮暗配色。
- **0.7.0 · 边唱边查词。** 谱面常驻注音、译文、罗马音、粤拼和查词开关，选中的词可直接修正读音。左栏可查看连接方式、歌词来源与时间轴，底栏可收藏当前歌曲或加入歌单；Windows 11 标题栏随主题换色。
- **0.8.0 · 桌面歌词也能对字跟唱。** 假名贴着对应汉字换行，特殊读法和手动分段保留。谱面顶部可直接调字号，底栏可单独调当前播放来源的音量，不动系统总音量。
- **0.8.1 · 钉住歌词，鼠标照常用。** 播放器可直接钉住浮窗，悬停三秒点小锁即可解锁。窗口置顶与文字底部阴影可独立开关，练唱稿的分隔线两侧自动留白。
- **0.8.2 · 自由翻看后再跟唱。** 滚轮遵循 Windows 滚动行数，也支持高精度滚轮和触控板的细小位移。可以拖动原生滚动条停在目标句；开启自动返回时，松手四秒后才回到当前句。
- **0.8.3 · 赞赏作者。** 左栏新增微信赞赏入口，赞赏码随包离线提供，查看时音乐继续播放。
