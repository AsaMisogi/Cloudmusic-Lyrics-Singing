# 咏伴 0.2.1

修复主界面快捷键随控件焦点改变含义的问题。

- 点击词典开关、跟随下拉框、按钮或滑块后，空格仍对应播放 / 暂停，不再额外操作该控件。
- 上下句、进度微调、单句循环与 A/B 点快捷键同样保持固定含义。
- 长按空格只切换一次；方向键仍可连续操作。文字输入、输入法组合、弹窗、Enter 与 Tab 保留正常交互。
- 保留网易云连接与路径设置、歌词注音、译文、查词、本地变速和循环功能。

下载 `Utatomo-0.2.1-windows-x64.zip`，完整解压后运行 `Utatomo.exe`。适用于 Windows 10 / 11 x64，无需安装 Python；请保留 `_internal` 文件夹。升级时保留原 `data/` 以沿用路径设置、显示偏好和注音修正。

验证：62 项离线单元测试、49 项真实 WebEngine 界面检查通过；另用真实按下 / 松开事件验证焦点下的快捷键和控件副作用。原有 8 项本地播放器验收继续通过，前端无脚本错误。本次未重启网易云。

Windows x64 便携版已构建，直接运行打包 EXE 的播放器验收通过；压缩包完整性和界面资源一致性已核对，不包含个人数据。
